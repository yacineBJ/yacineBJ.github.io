Market Analytics Pipeline

PreviousNext

Developed a real-time stock market data pipeline to capture, process, and visualize live financial data. The system ingests stock prices from the Polygon.io API and streams them into Apache Kafka for high-throughput buffering. Apache Spark consumes the stream to compute real-time metrics, such as 1-minute moving averages for each stock symbol. The processed data is stored in a MySQL database and visualized through Grafana dashboards, enabling real-time monitoring of stock trends. The project showcases expertise in streaming architectures, data engineering, and real-time analytics using Kafka, Spark, MySQL, and Grafana.
Frameworks: PySpark, Kafka, MySQL, Grafana
