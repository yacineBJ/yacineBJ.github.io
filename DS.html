Brain Tumor Classification

This project automates brain tumor detection and classification from MRI images using Deep Learning (CNNs) and transfer learning with DenseNet121. Images are preprocessed using Python, NumPy, and Pandas, including resizing, normalization, and data augmentation (rotation, flipping, zooming). The model is trained using fine-tuned convolutional layers with regularization to improve generalization. Performance reached 98% accuracy on internal data and 78% on external data. The model is deployed using Gradio to allow users to upload MRI images and view predictions with confidence scores.
Technologies: Python (Pandas, NumPy, Matplotlib, TensorFlow, Keras)
Machine Learning: Deep Learning, CNN, Transfer Learning, DenseNet121

Car Price Prediction

The goal of this project is to predict the price of a car based on various features using linear regression. We compare two different approaches to training the model: using a single variable (horsepower) and using multiple variables (all relevant features). The project involves exploratory data analysis (EDA), data transformations, and the application of machine learning techniques to build a predictive model.
Technologies: Python (Pandas, NumPy, Matplotlib, Scikit-learn)
