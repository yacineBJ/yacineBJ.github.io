Loan Predictor


This project aims to predict the number of loans a person has based on demographic and financial attributes such as age, income, gender, marital status, number of kids, number of credit cards, payment methods, mortgage status, and store card ownership. The process begins with Exploratory Data Analysis (EDA) to understand the data distribution, detect outliers, and identify correlations between features. Next, in the data preprocessing phase, missing values are handled, categorical variables are encoded, and numerical features are standardized to ensure optimal model performance. The dataset is then split into training and testing sets to build and evaluate two machine learning models: K-Nearest Neighbors (KNN) and Decision Tree Classifier. KNN, a distance-based algorithm, predicts based on similarity to the nearest neighbors, while the Decision Tree model captures complex patterns by splitting data based on feature importance. Both models are evaluated using accuracy, precision, recall, and F1-score to determine their predictive performance. Further improvements, such as hyperparameter tuning and class balancing, can enhance accuracy. Ultimately, this model provides financial institutions with valuable insights into customer loan behavior, potentially aiding in risk assessment and loan approval decisions.
Python: Pandas, NumPy, Matplotlib, Scikit-learn
Machine Learning: Linear Regression, One-Hot Encoding, StandardScaler.
